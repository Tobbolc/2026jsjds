农作物病虫害识别系统文档

1. 总体功能描述

本系统是一个基于深度学习的农作物病虫害识别和社区交流平台，主要包含以下功能模块：

  • 用户认证：登录、注册、密码找回
  • 病害识别：图像上传、自动识别、结果展示
  • 病害知识库：病害信息查询、防治方法
  • 社区讨论：发帖、评论、点赞、图片分享
  • 个人中心：历史记录、收藏管理

2. 运行环境

前端环境

  • uni-app框架
  • Vue.js 2.x
  • 微信开发者工具

后端环境

  • Python 3.8+
  • Flask框架
  • SQLAlchemy ORM
  • MySQL 8.0

3. 软件安装说明

前端安装

# 安装依赖
npm install

# 运行开发环境
npm run dev:mp-weixin

# 打开微信开发者工具
# 导入项目目录下的 dist/dev/mp-weixin 文件夹

后端安装

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt

# 初始化数据库
python init_db.py

# 运行服务
python app.py

4. 功能介绍

4.1 社区讨论功能

功能 说明
发布帖子 支持文字内容和最多9张图片，图片自动压缩
点赞互动 支持帖子点赞/取消，带动画效果
评论功能 支持发表评论，实时更新评论列表
图片预览 支持查看原图，多图左右滑动
内容展开 长文本自动折叠，点击展开全文

5. 规范文件

5.1 代码规范

  • 使用 ESLint 进行代码格式化
  • 遵循 Vue.js 官方风格指南
  • 使用 TypeScript 进行类型检查

5.2 文件结构

project/
├── src/
│   ├── pages/          # 页面文件
│   ├── components/     # 组件文件
│   ├── static/         # 静态资源
│   ├── utils/          # 工具函数
│   └── config.js       # 配置文件
├── server/
│   ├── app.py         # 后端主程序
│   ├── models/        # 数据模型
│   └── utils/         # 工具函数
└── docs/              # 文档文件

5.3 API 接口规范

接口 方法 说明
/api/posts GET 获取帖子列表
/api/posts POST 发布新帖子
/api/posts/:id/like POST 点赞/取消点赞
/api/posts/:id/comments GET/POST 获取/发表评论
