农作物病害识别模型训练文档

1. 模型架构

本项目使用了 ResNet50 作为基础模型：

  • 基础模型：ResNet50（预训练于ImageNet）
  • 输出层：61个类别（对应不同作物病害类型）
  • 图像输入尺寸：224×224 像素

2. 数据处理

2.1 数据增强

transforms.Compose([
    transforms.Resize((224, 224)),  # 调整图像大小
    transforms.RandomHorizontalFlip(),  # 随机水平翻转
    transforms.RandomRotation(10),  # 随机旋转
    transforms.ToTensor(),  # 转换为张量
    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])  # 标准化
])

2.2 数据加载

  • 批次大小：32
  • 训练集和验证集比例：8:2
  • 使用 DataLoader 进行批处理

3. 训练策略

3.1 优化器

  • 优化器：Adam
  • 学习率：0.001
  • 权重衰减：1e-4

3.2 学习率调度

使用 ReduceLROnPlateau 调度器：

  • 当验证损失停止改善时降低学习率
  • patience：5 epochs
  • 降低因子：0.1

3.3 早停机制

  • 监控指标：验证损失
  • patience：10 epochs
  • 保存最佳模型

4. 训练过程监控

  • 使用 TensorBoard 记录：
    • 训练损失
    • 验证损失
    • 训练准确率
    • 验证准确率
    • 学习率变化
  • 保存训练日志和模型检查点

注意事项：

  • 模型在训练过程中会自动保存最佳权重
  • 使用早停机制防止过拟合
  • 可以通过 TensorBoard 实时监控训练过程

5. 模型评估

模型在验证集上的性能指标：

  • 最佳验证损失：0.4179
  • 最佳验证准确率：85.18%

6. 使用说明

6.1 训练命令

python train.py

6.2 TensorBoard 可视化

tensorboard --logdir=logs

6.3 模型预测

python test.py
